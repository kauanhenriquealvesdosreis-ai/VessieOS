# System Name – Sistema Operacional Administrativo para Iniciantes

Bem-vindo ao **System Name**! Este projeto tem como objetivo fornecer uma base completa para a criação de um sistema operacional, com foco em **facilidade de uso**, **administração simplificada** e **código comentado** – perfeito para quem está começando no mundo do desenvolvimento de SOs.

---

## 📋 Descrição

O **System Name** é um sistema operacional didático, desenvolvido para que iniciantes possam entender os conceitos fundamentais de um SO (gerenciamento de processos, memória, sistema de arquivos, interface de usuário, etc.) de forma **prática** e **administrativa**. Todos os scripts e arquivos fonte contêm descrições detalhadas, explicando cada passo, para que você possa aprender enquanto constrói.

---

## 🚀 Funcionalidades

- **Interface amigável** (modo texto ou gráfico leve)  
- **Comandos administrativos** pré-configurados (gerenciamento de usuários, permissões, logs)  
- **Sistema de arquivos** simples e documentado  
- **Gerenciador de processos** com prioridades básicas  
- **Scripts de inicialização** (bootloader) comentados linha a linha  
- **Modularidade** – fácil adicionar ou remover componentes  
- **Totalmente open-source** e adaptável para seus estudos

---

## 🛠️ Requisitos

Para compilar e executar o System Name, você precisará de:

- **Sistema operacional hospedeiro**: Linux (recomendado) ou macOS com ferramentas GNU  
- **Compilador**: GCC / NASM (para assembly)  
- **Emulador**: QEMU (para testar sem hardware real)  
- **Make** (opcional, mas recomendado)  
- **Conhecimento básico** de C e Assembly (mas o código é bem explicado!)
